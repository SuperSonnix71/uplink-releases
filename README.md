# Uplink

Uplink is a macOS app for mounting remote folders in Finder.

This repository is for public downloads, release notes and update information. The Uplink source repository is private.

Downloads are not available yet. This release will be offered for noncommercial use only. The bundled FUSE T binary has separate commercial licence terms, so a free download does not by itself cover workplace use.

See the [FUSE T licence](https://github.com/macos-fuse-t/fuse-t/blob/1.2.7/License.txt) for its terms.

# Uplink

Uplink is a macOS app for mounting remote folders in Finder.

This repository is for public downloads, release notes and update information. The Uplink source repository is private.

Download [Uplink 1.0.0](https://github.com/SuperSonnix71/uplink-releases/releases/download/v1.0.0/Uplink-1.0.0.dmg) or read the [release notes](https://github.com/SuperSonnix71/uplink-releases/releases/tag/v1.0.0).

Uplink requires macOS 15.4 or later and includes FUSE T and SSHFS. Open the disk image, then open Uplink.pkg. The installer asks for administrator approval and installs Uplink in Applications. This build is not notarized. Do not disable macOS security protections to install it.

Future updates use the [update feed](https://supersonnix71.github.io/uplink-releases/appcast.xml). You can choose automatic checks in Settings or use Check for Updates. Installing a downloaded update through Sparkle still needs testing.

## 1.0.0

First public version, internal build 5. Installation of a downloaded Sparkle update has not been tested.

Uplink now ships as an Installer package inside its disk image. Installation places the app in Applications and adds the local `uplink` hosts alias while preserving saved connections and credentials. Finder mounts now identify their location as `uplink`.

Uplink appears in both the Dock and the menu bar while keeping one running app instance. Quit offers to unmount active connections first without automatically forcing an unmount that cannot finish. Mounted state refreshes after a volume is unmounted outside Uplink, and Open in Finder opens the configured mount after a successful mount.

The sidebar uses one stable control with filled icons for mounted drives and outline icons for unmounted drives. About credits Created by Sonny Mir and links to the repository and bundled dependency licenses.

The management window has a fixed content size of 823 by 750 and does not enter full screen. Installed build 5 testing confirmed fixed window bounds, resize rejection and sidebar behavior. The user approved its appearance and confirmed mounting, unmounting and the manual update check work. This did not test installing a downloaded update through Sparkle. The sidebar has a bounded width. Connection details retain native scrolling, wrap long values and allow text selection.

Release tooling verifies the existing signing key and archive signature before upload. New update entries identify the Installer package and preserve previous feed entries and release notes. Package updates require administrator approval. Automatic update checks remain user controlled in Settings.
